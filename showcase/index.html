01 · UNDERSTAND THE MODEL

Four logical coordinates.
One selected value.

This is not a claim about four physical dimensions. It is a way to address candidate values in a catalogue, while an actual matrix selects just one palette entry for each position and state.

X

Horizontal

Column of the effective grid, from 0 to 63.

Y

Vertical

Row of the effective grid, from 0 to 63.

C

Palette dimension

One of at most 64 indexed hexadecimal entries.

T

Temporal state

One of up to 64 complete frames in the working profile.

Catalogue Ω = X × Y × T × C → 64⁴ = 16,777,216 candidate tuples

The catalogue count is not the amount of encoded payload. With 64 palette entries, each selected module carries 6 bits; the maximum profile stores 192 KiB of raw module selections per 64-frame cycle.
